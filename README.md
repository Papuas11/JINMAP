# JINJA MAPS

A clean, production-ready Next.js foundation for a business map platform focused on Jinja, Uganda.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Routes

- `/` — Public homepage shell
- `/admin` — Admin dashboard shell
- `/admin/login` — Admin login shell

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Notes

- This step intentionally includes only UI foundations.
- No database, authentication logic, map integration, or CRUD is included yet.
